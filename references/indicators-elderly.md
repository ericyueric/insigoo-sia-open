# L2 参考指标集 · 养老服务类（5核心 + 3补充）

> 适用：居家养老、社区养老、机构养老、老年健康、适老化改造、老年关爱等以"老年人生活质量与健康结局改善"为核心成果的公益项目。
> 性质：**参考指标集而非强制指标**——项目可替换，但必须说明替换理由，并保持"产出/成果/影响"分层结构。

## 核心指标（成果层，必选≥3）

| # | 指标 | 定义/公式 | 数据来源 | 测量频率 |
|---|------|----------|---------|---------|
| O1 | 健康/功能状态改善 | ADL/IADL 日常生活能力量表、慢病控制率等前后对比变化（需基线） | 健康评估、随访记录 | 半年/年度 |
| O2 | 照护可及性/覆盖率 | 可及的养老服务覆盖率、上门服务/助餐助洁等覆盖比例 | 服务记录系统 | 月度/季度 |
| O3 | 社会参与/孤独感改善 | 社会参与度、孤独量表（如 UCLA 孤独量表）得分变化 | 量表测评 | 半年 |
| O4 | 安全事故率下降 | 跌倒、意外发生率的同比/环比变化 | 安全事件记录 | 季度/年度 |
| O5 | 照护者负担缓解 | 照护者负担量表（如 Zarit）得分变化（影响层） | 量表测评 | 半年 |

## 补充指标（产出层，可选）

| # | 指标 | 说明 |
|---|------|------|
| O6 | 服务人次 / 设施床位数 | 基础产出，**不可单独作为成果** |
| O7 | 适老化改造户数 | 完成改造的户数（产出层，不直接等于生活质量改善） |
| O8 | 老年人/家属满意度 | 需规范量表 + 抽样说明，否则按 D 级证据计 |

## 指标与证据等级的联动规则

- O1 量表测评有基线对照 → **B 级**；单次快照最高 **C 级**
- O2 服务记录系统可追溯 → **C 级**（经第三方核验可达 B 级）
- O3/O5 规范量表前后测 → **B 级**（无基线 C 级）
- O4 事件记录有对照 → **B/C 级**
- O6-O7 为产出层 → 不影响 D2 评级，仅支撑 D3 覆盖率
- O8 满意度问卷无抽样说明 → 按 **D 级**证据计

## 使用规则

1. **必选约束**：核心指标至少选用 3 项；项目可替换指标，但需说明理由并保持分层结构。
2. **分层校验**：O6-O8 为产出层指标。项目若只有产出层数据（如"服务 X 人次、改造 X 户"）而无 O1-O5 类成果指标，D1 评分不得高于 14 分档（见 l2-scoring-rubrics.md）。
3. **常见踩坑**（来自百项快检养老类高频问题）：
   - "服务 X 人次、建设 X 张床位"当唯一成果 → 产出冒充成果，D1 失分
   - "老年人很开心"无量表、无前后测 → 按 D 级证据计，且不构成成果证据
   - 适老化改造户数（O7 产出）≠ 生活质量改善（O1 成果）：改造完成不代表老人功能状态提升，须分别测量
   - 混淆"覆盖率"与"改善度"：O2 是服务可及（过程），O1 是健康结局（结果），二者不可互相替代
4. **典型项目参照**：设施/改造投入（O6/O7）→ 服务可及（O2）→ 健康功能改善（O1）+ 社会参与（O3）→ 安全下降（O4）+ 照护者减负（O5），是养老 ToC 链；数据断点常在"服务可及→健康结局"之间（有服务记录、缺功能状态追踪）。
