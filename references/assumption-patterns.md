# 常见隐式假设模式库

中国公益项目高频踩坑点，评估时逐项比对。

| # | 隐式假设 | 为什么不靠谱 |
|---|---------|-------------|
| 1 | 培训了老师 = 教学质量提升 | 培训→老师行为改变→课堂教学变化→学生学习成果，中间缺多环 |
| 2 | 发了物资 = 需求被满足 | 物资是否适配真实需求？受益人会不会用？用完之后呢？ |
| 3 | 办了活动 = 意识提升 | 参与≠改变，一次性活动的效果衰减极快 |
| 4 | 建了平台/小程序 = 有人会来用 | 获客、留存、活跃三个环节全部未经证 |
| 5 | 服务覆盖了 = 受益发生了 | 接触≠受益，服务深度和实际改变未验证 |
| 6 | 受益人满意 = 项目有效 | 满意度≠改变，存在社会赞许偏差 |
| 7 | 资金到位 = 项目能落地 | 执行团队能力、合作伙伴配合度、外部环境均未验证 |
| 8 | 做了倡导 = 政策会改变 | 政策窗口、联盟力量、倡导路径均未验证 |
| 9 | 今年有效 = 明年还有效 | 效果的持续性、对资助的依赖性未验证 |
| 10 | 没有我们他们就不行 | 死重假设——受益人可能通过其他渠道获得同类帮助 |
