# D1 组织尽调（KYB）八维与本地化数据源

> 八维对齐 GMF（原六维中的「效果与效能」按 GSA 拆为财务 / 执行 / 影响三维，见 §10.1 修订）。成熟度采用 GSA 0–3 量尺语义 + D1-A~D 简版标签。

## 八维（+ 条件性伙伴视角）

| 维度 | 核心问题 | 本地化核验源 |
|---|---|---|
| 宗旨与影响力 | 使命是否清晰、有无变革理论、是否对齐 SDG | 机构章程、项目书 |
| 领导力 | 理事会构成、独立性、社区代表 | 年报、理事会名单 |
| 诚信 | 行为准则、利益冲突政策、举报机制 | 制度文件 |
| 透明度与问责 | 年报 / 财报是否公开审计、受益人反馈机制 | 慈善中国、财务披露 |
| 沟通与舆情 | 官网 / 传播 + 组织 / 项目 / 其他项目的新闻与舆论正负面、辟谣 | 公开渠道 + 新闻检索 |
| 财务健康(Finance) | 财务手册、成本规则、审计轨迹、审计/财报质量 | 审计报告、财务报表 |
| 执行效能(Delivery) | 项目 SOP、采购政策、风险登记、报告与付款日历 | 项目档案、执行记录 |
| 影响成效(Impact) | MEAL 计划、指标基线/目标、经验沉淀 | 监测与评估报告 |
| 伙伴（条件） | 仅当组织有分包 / 联合资助 / 下游执行方：对伙伴的尽调与不利媒体筛查 | MoU / 分包协议（§10.1 修订） |

## 本地化数据源（替换 MAS/COC/Singpass）
- 慈善中国（cishan.chinanpo.gov.cn）— 慈善组织认定、公开募捐资格
- 中国社会组织公共服务平台 — 登记状态、年检
- 民政部信用信息公示 — 行政处罚、异常名录
- 国家企业信用信息公示系统 — 发起人关联企业
- 公开舆情与新闻检索（搜索引擎 / 新闻库 / 社交媒体 / 投诉平台 / 监管通报）— 覆盖组织、发起人、项目及**组织其他项目**

## 成熟度分级（GSA 0–3 量尺）
- **3 = D1-A 成熟期**：治理完备、财务透明、有独立审计；各维度书面化 + 可举证有效
- **2 = D1-B 进阶期**：主要维度达标，个别需改进
- **1 = D1-C 基础期**：框架具备但执行薄弱
- **0 = D1-D 萌芽期**：治理 / 财务存在重大缺口

## 舆情检索（跨 D0/D1/D2 外部信号层）
- 检索对象：① 组织全称 / 简称 / 曾用名；② 发起人姓名 + 机构职务；③ 目标项目名称；④ 该组织其他在运项目（交叉验证"是否系统性问题"）
- 评估口径：正 / 中 / 负向；来源权威性；是否已被辟谣；时效性（近 3 年权重更高）；是否相关本项目
- 风险处置：命中"不利媒体 / 重大负面 / 未辟谣指控" → 触发对应层复核（D0 诚信、D1 沟通、D2 成果可信度），必要时降级或上报
- **红线**：仅输出「检索指引 + 命中来源清单 + 摘要 + 建议复核项」，禁止自动全网抓取与自动定性（国际 AML/KYC 共识支持，见设计文档 §10.2）
