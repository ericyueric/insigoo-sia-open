# L3 参考文献

> 本框架 L3 价值评估层建立在 SROI（Social Return on Investment）领域通行方法论之上。
> 下列来源按性质分列：**方法论基础**（框架的学理依据）与**中文科普参考**（概念引入与命名对照的辅助读物）。

---

## 一、方法论基础

| 来源 | 说明 |
|------|------|
| **Social Value International (SVI), _A Guide to Social Return on Investment_** | SROI 方法论的国际通行框架。反事实四要素（Deadweight / Attribution / Displacement / Drop-off）与货币化路径为其标准组成。本框架 L3 的 §2 四系数、§3 货币化三法即在此框架内工程化实现 |
| **OECD/DAC 评估标准** | 相关性 / 有效性 / 效率 / 影响 / 可持续性五准则。本框架 v2.2 模块 C 以轻量追问方式承接其可持续性与效率两项 |

> 说明：反事实四要素与货币化三法属 SROI 领域**通行方法**，非任一机构或个人独创。
> 本框架对其取值规则、净贡献公式、双重扣减红线的**工程化处置由 insigoo 独立给出并负责**。
