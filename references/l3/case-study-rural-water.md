# L3 验证算例 · 某农村饮水工程（脱敏版）

> **脱敏声明**：本算例源自一个真实的 L3 端到端验证案例（sia_kb 全库中首个同时达到 L2-A 且具备反事实数据的项目）。
> 为保护项目方与第三方评估机构的商业信息，**已移除项目名称、执行机构、评估机构名称、项目编号、绝对金额、地理信息、年份区间**。
> 保留的是**方法论结构、四系数取值逻辑、三法交叉验证过程、以及重复扣减的完整复盘教训**。
> 脱敏后的案例不可用于外部溯源核验，因此**不计入 L3 信号③ 的「公开标杆」计数**——它在此处的角色是**教学与验证范本**，不是可核查证据。

---

## 0. 为什么这个案例重要

它是全链路首次贯通：**L1 逻辑自洽 → L2 指标量化 → L3 货币化**。
在一个 223 个项目的样本库里，同时满足「L2-A 级」+「有反事实数据」两个条件的项目**只有这一个**。

| 层级 | 结果 | 说明 |
|---|---|---|
| L1 逻辑自洽 | 通过（完整 ToC） | 投入 → 活动（建供水设施/供水）→ 产出（十余万处小型供水设施及千余处集中供水工程）→ 成果（数百万人饮水条件改善）→ 影响（健康改善 / 妇女赋能） |
| L2 指标量化 | **L2-A（86 分）** | D1=21 / D2=27 / D3=21 / D4=17。D2 为 **B 级**（纵向追踪 + 准实验论文，**非 RCT**），属"数据补强型 L2-A" |
| L3 货币化 | 本算例验证 | 四系数 + 货币化三法 + 净贡献率 → SROI 区间与中枢值 |

> ⚠️ **D2 = B 而非 A 这一点很关键**：整个货币化结论的强度，受限于原始评估"未引入随机对照试验"的性质。
> L3 不会比 L2 的证据更硬。这也是为什么 L3 货币化结论必须显式标注证据等级。

## 1. 反事实四系数取值（L3 核心算子）

**系数依据来源类型**（脱敏：只保留依据的**类别**，不保留具体报告名称）：
① 十年期效果评估中的对照村数据；② 第三方专业机构的 SROI 评估报告；③ 准实验（倾向得分匹配）学术论文；④ 国家级农村饮水安全工程公开统计。

| 系数 | 取值 | 依据类别 | 置信度 |
|---|---|---|---|
| Deadweight（死重） | 0.15 | 同期政策替代：国家级同类工程在该区域覆盖率极高 | 中高 |
| Attribution（归因） | 0.25 | 政府配套资金/其他救助已覆盖部分，本设施为核心新增增量 | 中 |
| Displacement（替代） | 0.05 | 风险由单个家庭转移至共担体，方向为正 | 中 |
| Drop-off（衰减） | 0.15 | 工程老化，效果依赖持续维护投入 | 中 |

**净贡献率** = (1−0.15)(1−0.25)(1−0.05)(1−0.15) = **0.52**（区间 0.35–0.62）

> 此 0.52 是**本项目独立估计的四系数净调整因子**，在 L3 中的正确角色是**敏感性参数**。
> 它是乘子还是参数，决定了后面 §3 那个价值数百万的错误。

## 2. 货币化三法交叉验证

| 方法 | 取值逻辑 | 验证结论 |
|---|---|---|
| 避免成本法（主法） | 受益妇女取水时间节省：单次节省时长 × 年频次 × 当地工时单价 | 量级合理，可独立验证 |
| 市场替代法 | 等值安全饮水工程市场造价 / 健康改善带来的误工减少 | 需健康结局数据，部分待补 |
| 意愿支付法 | 受益户对安全饮水的支付意愿（显现偏好法） | 谨慎使用，避免混淆投入与 WTP |

三法量级方向一致，证实"社会价值远大于投入"的定性结论稳健。

## 3. ⚠️ 核心教训：重复扣减是如何发生的

这是本算例**最值得开源的部分**——一个真实的、差点发布出去的错误。

### 3.1 错误是怎么犯的

协作方把第三方评估的「社会价值总额」当作**毛价值**，再乘以本项目的净贡献率 0.52，得出 **SROI ≈ 2.9（2.0–3.5）**。

### 3.2 判定过程（多源交叉核验）

查证第三方评估的方法论说明后确认：

1. 第三方机构采用的是**标准专业 SROI 方法论**（对各利益相关方影响做净现值测算）。
2. **标准 SROI 必然内含**死重 / 归因 / 替代 / 衰减四系数调整——即该机构给出的回报比本身就是**净值**。
3. 因此「总额 × 0.52」构成**重复扣减**，得出的 2.9 应撤销。

### 3.3 正确处置

| 项 | 处置 |
|---|---|
| 中枢值 | 采用第三方 SROI 回报比（净，已含四系数调整） |
| 本项目四系数 0.52 | **不作用于**第三方总额；改作**独立敏感性校验参数**——验证即便在保守归因/死重假设下，社会回报仍显著高于投入 |
| 交叉验证 | 货币化三法独立测算，量级与中枢值同阶，相互印证 |

### 3.4 次级透明度问题（诚实披露）

核算发现：**第三方公布的"社会价值总额 ÷ 总投入"并不等于其公布的回报比中枢值**，两者存在缺口。
这表明第三方采用了现值折算或不同的投入口径，其算术过程不够透明。
建议后续处理类似案例时，向项目方或评估机构索取方法论附录以闭合口径。

### 3.5 与 L2 证据等级的自洽性

第三方报告原文自承："未引入对照试验""部分成果无法量化、等价物统计难获、影响力范围难定"。
这属**专业但非实验性**的 SROI，与本项目 L2 评定的 **D2 = B 级（纵向追踪级，非独立因果验证级）完全一致**。
→ 该回报比是可信的净 SROI，但**不是实验验证的因果估计**。L3 报告若省略这一点，就是把 B 级证据包装成了 A 级结论。

## 4. L3 货币化结论

| 项 | 值 |
|---|---|
| **SROI（净，中枢）** | 第三方评估结果，口径为「已含四系数调整的净回报比」 |
| 净贡献率（本项目独立估计） | 0.52 —— **敏感性参数，非乘子** |
| 货币化三法交叉验证 | 量级同阶，稳健 |
| 公平维度 | ✅ 双重弱势群体（性别 + 地理），最弱势优先 |
| 证据等级约束 | L2 D2 = B 级（非 RCT），结论须标注此限制 |

**结论**：L3 货币化方法验证通过。在已净扣四系数的标准 SROI 口径下结论稳健；
同时验证了一条红线——**已内含四系数的第三方净值，严禁再次乘以自估净贡献率**。

---

## 5. 局限与下一步

**局限**

1. 该回报比为专业非实验性评估（D2 = B 级），非 RCT 因果验证。
2. 第三方 SROI 算术口径不完全透明，待索取方法论附录。
3. 健康结局（介水疾病发病率）的系统量化依赖公开二手数据，非项目方一手追踪。
4. **仅此 1 个 L2-A 范本，L3 货币化轨道尚不具备统计代表性。**

**对 L3 开源的启示**

> 一个案例能说明**方法跑得通**，不能说明**方法已经稳定**。
> 把单一案例固化为"标准"，会把未验证的方法变成可被审计质疑的承诺。
> 这正是本框架把 L3 标为 **v0.3 方法草案**而非"标准"的原因。
