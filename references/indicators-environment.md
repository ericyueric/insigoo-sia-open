# L2 参考指标集 · 自然保护/河湖保护类（5核心 + 3补充）

> 适用：自然保护、河湖保护、生态修复、环保倡导（含行为指标）等以"环境与生态改善"为核心成果的公益项目。
> 设计依据：环保核心指标"5+3"决策（5 核心聚焦成果 + 3 补充覆盖产出）+ 百项快检发现"政策改变与种群级科考数据是更接近成果层级的证据"。
> 性质：**参考指标集而非强制指标**——项目可替换，但必须说明替换理由，并保持"产出/成果/影响"分层结构。

## 核心指标（成果层，必选≥3）

| # | 指标 | 定义/公式 | 数据来源 | 测量频率 |
|---|------|----------|---------|---------|
| E1 | 环境质量变化率 | 项目区域水质/空气/土壤关键指标的变化（对照官方监测数据） | 官方监测站 / 第三方检测 | 季度/年度 |
| E2 | 政策/制度改变 | 推动出台的政策、标准、补偿机制数量与级别 | 政策文件 | 事件驱动 |
| E3 | 目标群体行为改变率 | 发生环保行为改变的人数/比例（需前后对照） | 行为调查 / 参与数据 | 年度 |
| E4 | 生态/物种修复 | 种群数量、栖息地面积、生物多样性指数变化 | 科考报告 / 监测数据 | 年度 |
| E5 | 社区利益相关方改变 | 社区居民参与率、环保相关收入变化 | 社区调查 | 年度 |

## 补充指标（产出层，可选）

| # | 指标 | 说明 |
|---|------|------|
| E6 | 环境问题发现与响应数 | 某河湖保护志愿者平台已有成熟数据（问题上报/响应率） |
| E7 | 触达人数及覆盖率 | 须区分曝光/触达/深度参与三档 |
| E8 | 知识/意识提升度 | 须有前后测，单次问卷按 D 级证据计 |

## 指标与证据等级的联动规则

- E1/E4 引用官方监测数据 → 可达 **B 级**证据
- E2 有正式政策文件 → 可达 **B 级**证据
- E3/E5 自报问卷无对照 → 最高 **C 级**
- E6-E8 为产出层 → **不影响 D2 评级**，仅支撑 D3 覆盖率

## 使用规则

1. **必选约束**：核心指标至少选用 3 项；项目可替换指标，但需说明理由并保持分层结构。
2. **分层校验**：E6-E8 为产出层指标。项目若只有产出层数据（如"巡查 X 次、上报问题 X 件"）而无 E1-E5 类成果指标，D1 评分不得高于 14 分档（见 l2-scoring-rubrics.md）。
3. **常见踩坑**（来自百项快检）：
   - "覆盖 X 万人次"：曝光量 ≠ 触达 ≠ 受益，且无去重 → D4.4 失分
   - "水质明显改善"无官方监测断面数据对照 → 无法支撑 E1，按描述性证据计
   - 志愿者活动参与人次当作"行为改变" → 参与 ≠ 改变，E3 需前后对照
4. **典型项目参照**：巡查任务发布→志愿者参与→巡查行为→问题发现→问题响应→环境改善，是一条典型的河湖保护 ToC 链；评估 D3 时注意"问题被解决"之后的转化节点（响应→解决→水质改善）最容易断数据。
