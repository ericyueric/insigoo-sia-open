# D0 发起人尽调（KYC）字段集与核验指引

> 定位：合规与诚信护栏，**非**个人背景监视。涉 PII 须知情同意 + 最小必要采集，存储纳入 sia_kb 治理（脱敏 / 留存期 / 访问审批）。

## 字段集（精简版，小资助用）

| 类别 | 字段 | 核验方式 |
|---|---|---|
| 基本身份 | 姓名、机构职务、从业年限 | 机构公示 / 公开资料 |
| 利益关联 | 是否在被评估项目中有直接或关联交易 | 自我披露 + 交叉核验 |
| 关联企业 | 担任法人 / 股东的企业名单 | 国家企业信用信息公示系统 |
| 诚信记录 | 是否涉未决诉讼 / 行政处罚 / 公募资格异常 | 信用中国 / 裁判文书网 |
| 舆情与新闻 | 发起人相关负面报道、争议、辟谣情况 | 公开检索（仅检索指引 + 人工判定） |
| 关键人 / 创始人风险信号 | 历史创办 / 任职机构的关停或争议记录；是否 multiple 项目中重复担任发起人 | 公开资料交叉（§10.3 新增） |

## 风险分级
- **通过**：公开信息一致、无关联冲突、无未决诚信记录
- **补披露后通过**：存在关联但已披露、或信息缺口，补充说明后通过
- **否决 / 上报**：隐瞒关联、重大诚信记录、利益冲突未规避，或触发"创始人红灯"

## 红线（强制）
- PII 知情同意 + 最小必要；存储入 sia_kb
- **创始人红灯**：创始人 / 核心发起人存在重大诚信记录或隐瞒关联 → 直接否决并留痕
- 舆情仅输出「检索指引 + 命中清单 + 摘要 + 建议复核项」，**禁止自动全网抓取与自动定性**
