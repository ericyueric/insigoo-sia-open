# L2 参考指标集 · 医疗救助类（5核心 + 3补充）

> 适用：医疗救助、大病救助、罕见病援助、医疗补贴等以"改善患者治疗结局"为核心成果的公益项目。
> 性质：**参考指标集而非强制指标**——项目可替换，但必须说明替换理由，并保持"产出/成果/影响"分层结构。

## 核心指标（成果层，必选≥3）

| # | 指标 | 定义/公式 | 数据来源 | 测量频率 |
|---|------|----------|---------|---------|
| M1 | 救助完成率 | 完成全程治疗的获助人数 / 获助总人数 | 执行数据 + 医疗文书 | 逐例 |
| M2 | 治疗结局改善 | 康复率 / 缓解率 / 生存率（按病种定义） | 医疗记录 / 随访 | 治疗后 6-12 月 |
| M3 | 救助及时性 | 确诊到获得救助的中位时间 | 申请与拨款记录 | 逐例 |
| M4 | 家庭灾难性医疗支出变化 | 获助家庭发生灾难性医疗支出的比例变化（需基线） | 家庭调查 | 年度 |
| M5 | 受益人生存质量变化 | 标准量表（如 EQ-5D）前后对比 | 量表测评 | 救助前后 |

## 补充指标（产出层，可选）

| # | 指标 | 说明 |
|---|------|------|
| M6 | 救助人次 / 例数 | 基础产出，**不可单独作为成果** |
| M7 | 资金执行率与拨付及时性 | 执行效率指标 |
| M8 | 受益方满意度 | 需规范量表 + 抽样说明，否则按 D 级证据计 |

## 使用规则

1. **必选约束**：核心指标至少选用 3 项；若项目声称的成果超出本表覆盖（如特定病种专科指标），可增补但需给出完整四要素（定义 + 计算公式 + 数据来源 + 测量频率）。
2. **分层校验**：M6-M8 为产出层指标。项目指标体系中若只有 M6-M8 类产出指标而无 M1-M5 类成果指标，D1 评分不得高于 14 分档（见 l2-scoring-rubrics.md）。
3. **与证据等级的联动**：
   - M1/M3 来自执行系统与医疗文书、可逐例核查 → 通常支撑 C 级证据；经第三方核验后可达 B 级
   - M2 依赖随访与医疗记录，随访率过低（如 <60%）属方法瑕疵，证据降一级
   - M4/M5 有基线 + 规范量表 + 合理抽样 → 可达 B 级；无基线的单次测量最高 C 级
   - M8 满意度问卷无抽样说明 → 按 D 级证据计
4. **常见踩坑**：
   - "救助 X 人次"作为唯一成果 → 产出冒充成果，D1 失分
   - "康复率 90%"无病种定义、无随访时间窗 → D4.2 失分
   - 患者自报经济状况无校验 → 存在回忆偏差，D4.4 降档
