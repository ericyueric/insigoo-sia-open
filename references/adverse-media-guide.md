# 舆情与新闻检索评估指引（人工判定红线）

## 检索对象
1. 组织全称 / 简称 / 曾用名
2. 发起人姓名 + 机构职务
3. 目标项目名称
4. 该组织其他在运项目（交叉验证"是否系统性问题"）

## 检索源
搜索引擎、新闻数据库、社交媒体、投诉平台（如黑猫投诉）、监管通报、行业社群。

## 评估口径
正 / 中 / 负向判定；来源权威性；是否已被辟谣；时效性（近 3 年权重更高）；是否与本项目相关。

## 风险处置
命中"不利媒体 / 重大负面 / 未辟谣指控" → 触发对应层复核（D0 诚信、D1 沟通、D2 成果可信度），必要时降级或上报。

## 红线（强制，人工判定）
- **仅输出**：「检索指引 + 命中来源清单 + 摘要 + 建议复核项」
- **禁止**：自动全网抓取、自动定性（工具只出"命中"不出"决定"——Sanction Scanner / Checklynx / Wolfsberg / Cedar Rose 共识）
- 最终判定权在评估人 / 资助方；须记录"**指控 vs 已证实**""**来源层级**""**实体是否同一**"三项判断并留痕

## 与 AVPN 对齐
对应 KYC/KYB 的"不利媒体筛查"字段；AVPN 依赖 LSEG World-Check 等境外商业库，国内落地以公开检索 + 本地投诉 / 监管源替代，不引入境外付费库依赖。
