# D2 成果核验（KYI）桥接 L2 证据五级

> 原则：KYI 的 Rigor / Relevance / Validity 三维与 L2 证据五级 A–E 是**同一件事**，直接建映射复用，不重复建设（设计文档 §4）。

| KYI 维度 | L2 对应 | 说明 |
|---|---|---|
| Rigor（方法学强度：轶事 → RCT） | L2-D2 证据五级 A→E | 直接引用 L2 已评定的证据等级 |
| Relevance（代理指标贴合度） | L2-D1 指标质量 | 是否"拿活动量充成果" |
| Validity（证据基础） | L2-D3 因果链覆盖 | 方法是否被"what works"佐证 |
| 归因 | L2 归因 | 成果是否由本项目真实产生（反事实 / 贡献声明） |

**D2 输出** = 直接引用 L2 已评定的证据等级 + 标注"成果是否由本项目真实产生（归因）"。

**证据五级（直接复用 L2）**：A 独立因果验证 / B 纵向追踪验证 / C 系统内部数据 / D 描述性证据 / E 无有效证据。
