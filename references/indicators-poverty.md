# L2 参考指标集 · 扶贫/乡村振兴类（5核心 + 3补充）

> 适用：产业扶贫、易地搬迁后续扶持、收入提升、技能培训、基础设施与公共服务改善、集体经济组织培育等以"农户生计改善与可持续脱贫"为核心成果的公益项目。
> 性质：**参考指标集而非强制指标**——项目可替换，但必须说明替换理由，并保持"产出/成果/影响"分层结构。

## 核心指标（成果层，必选≥3）

| # | 指标 | 定义/公式 | 数据来源 | 测量频率 |
|---|------|----------|---------|---------|
| P1 | 人均可支配收入变化 | 获助户人均可支配收入相对基线或对照组的净变化（需基线） | 入户调查、记账、统计台账 | 年度 |
| P2 | 稳定脱贫/不返贫率 | 监测期内未返贫户数 / 纳入监测总户数 | 动态监测台账 | 季度/年度 |
| P3 | 就业与产业可持续 | 就业率、产业项目持续运营率、集体经济增收额 | 产业台账、就业登记 | 年度 |
| P4 | 基础设施/公共服务可及性 | 安全饮水、道路通达、医疗教育等可及性改善覆盖率 | 设施普查、官方数据 | 年度 |
| P5 | 内生动力/能力建设 | 农户技能掌握率、组织化程度（合作社/互助组参与率） | 能力评估、组织台账 | 年度 |

## 补充指标（产出层，可选）

| # | 指标 | 说明 |
|---|------|------|
| P6 | 直接帮扶户数 / 资金投入 | 基础产出，**不可单独作为成果** |
| P7 | 项目资产形成与管护 | 形成的设施/设备类资产及后续管护机制（产出层） |
| P8 | 受益方满意度 | 需规范量表 + 抽样说明，否则按 D 级证据计 |

## 指标与证据等级的联动规则

- P1 有基线 + 对照组/准实验 → **B 级**（独立对照可达 A 级）；仅有获助后收入、无基线 → **C 级**；自报无校验 → 存在偏差风险，降档
- P2 动态监测数据系统可追溯 → **C 级**（经第三方核验可达 B 级）
- P3 产业/就业台账可核查 → **C 级**
- P4 引用普查或官方数据 → **B 级**
- P6-P7 为产出层 → 不影响 D2 评级，仅支撑 D3 覆盖率
- P8 满意度问卷无抽样说明 → 按 **D 级**证据计

## 使用规则

1. **必选约束**：核心指标至少选用 3 项；项目可替换指标，但需说明理由并保持分层结构。
2. **分层校验**：P6-P8 为产出层指标。项目若只有产出层数据（如"投入 X 万元、帮扶 X 户"）而无 P1-P5 类成果指标，D1 评分不得高于 14 分档（见 l2-scoring-rubrics.md）。
3. **常见踩坑**（来自百项快检扶贫类高频问题）：
   - "投入 X 万元、帮扶 X 户"当成果 → 产出冒充成果，D1 失分
   - "户均增收 X 元"无基线、无对照、靠自报 → D4.4 失分，且因果归属存疑
   - 易地搬迁"搬得出"≠"稳得住"：搬迁完成（P6/P7 产出）不等于收入可持续（P1/P3 成果），须分别测量
   - 产业项目"建得成"≠"运营得住"：P3 的"持续运营率"是关键成果，不能只看建设数
4. **典型项目参照**：资金投入 → 产业/就业载体形成（P3/P7）→ 农户增收（P1）→ 不返贫（P2）→ 内生能力（P5），是扶贫 ToC 链；数据断点常在"载体形成→持续增收"之间（有建设记录、无运营与收入追踪）。
