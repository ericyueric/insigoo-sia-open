# L2 参考指标集 · 教育助学类（5核心 + 3补充）

> 适用：助学帮扶、乡村教育、教育公平、阅读/素养提升、留守/困境儿童教育支持等以"学习成果与教育机会改善"为核心成果的公益项目。
> 设计依据：百项快检发现"教育类项目指标分化最剧烈"——大量项目停留在'资助人次/物资发放'产出层，而真正反映教育质量的'学习成效/机会可及性'成果指标普遍缺失，L2 价值最大。
> 性质：**参考指标集而非强制指标**——项目可替换，但必须说明替换理由，并保持"产出/成果/影响"分层结构。

## 核心指标（成果层，必选≥3）

| # | 指标 | 定义/公式 | 数据来源 | 测量频率 |
|---|------|----------|---------|---------|
| J1 | 学习成效提升率 | 标准化学业测评（期末/统考/第三方测评）前后对比的提升幅度，或毕业率/升学率变化 | 学业测评、学籍系统 | 学期/学年 |
| J2 | 受教育机会可及性改善 | 目标群体入学率/辍学率/巩固率变化（需基线对照） | 学籍系统、学校记录 | 学年 |
| J3 | 关键能力/素养达成 | 除学科外，阅读素养、21世纪技能等达标率（如阅读水平达标率） | 素养测评 | 学年 |
| J4 | 教育公平修复度 | 弱势学生（留守/贫困/残疾）与群体均值的成绩或机会差距缩小程度 | 分层测评 | 学年 |
| J5 | 长期发展结果 | 毕业去向追踪：继续升学率、稳定就业率、社会流动（影响层） | 校友追踪 | 毕业后 1-3 年 |

## 补充指标（产出层，可选）

| # | 指标 | 说明 |
|---|------|------|
| J6 | 直接服务人次 / 覆盖学校数 | 基础产出，**不可单独作为成果** |
| J7 | 师资与教学支持供给 | 培训教师数、教学资源/设备投放、教研支持（产出层） |
| J8 | 受益方/家长满意度 | 需规范量表 + 抽样说明，否则按 D 级证据计 |

## 指标与证据等级的联动规则

- J1/J2 引用学籍系统、统考或第三方测评数据（有基线对照）→ 可达 **B 级**；含独立对照组/准实验 → **A 级**
- J3/J4 规范素养测评有基线对照 → **B 级**；无基线的单次测量最高 **C 级**
- J5 纵向校友追踪（跨年）→ **B 级**；横断面快照最高 **C 级**
- J6-J7 为产出层 → 不影响 D2 评级，仅支撑 D3 覆盖率
- J8 满意度问卷无抽样说明 → 按 **D 级**证据计

## 使用规则

1. **必选约束**：核心指标至少选用 3 项；若项目声称的成果超出本表覆盖（如特定职教技能认证率），可增补但需给出完整四要素（定义 + 计算公式 + 数据来源 + 测量频率）。
2. **分层校验**：J6-J8 为产出层指标。项目指标体系中若只有 J6-J8 类产出指标而无 J1-J5 类成果指标，D1 评分不得高于 14 分档（见 l2-scoring-rubrics.md）。
3. **常见踩坑**（来自百项快检教育类高频问题）：
   - "资助 X 名学生、发放 X 册书"作为唯一成果 → 产出冒充成果，D1 失分
   - "成绩明显提升"无前后测对照、无控制变量说明 → D4.2 失分，最高 C 级
   - "满意度很高"无量表、无抽样 → 按 D 级证据计，且不构成成果证据
   - 混淆"入学率"与"学习成效"：入学可及（J2）≠ 学得好（J1），二者需分别测量
4. **典型项目参照**：助学金发放 → 学生返校（J2 可及性）→ 学习投入 → 学业提升（J1）→ 素养/公平修复（J3/J4）→ 长期发展（J5），是典型的助学 ToC 链；数据断点常在"返校→学习成效"之间（有资助记录、无学业测量）。
