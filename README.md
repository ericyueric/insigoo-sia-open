## 这是什么

insigoo-sia 是一个 AI 技能包（Skill），把 **insigoo SIA 社会影响力评估框架** 变成 AI 可直接执行的评估流程。把公益项目方案或执行材料喂给它，它会像体检医生一样输出**带优先级的诊断报告与处方**。

**v3.0.0 起，L2 指标量化层全开源**——完整评分锚点、证据五级定级规则、标杆案例库、五类参考指标集全部随包分发，可离线运行、无付费门槛。

## 三层体系

| 层级           | 回答的问题         | 状态                              | 开源情况                 |
| ------------ | ------------- | ------------------------------- | -------------------- |
| **L1 逻辑自洽层** | 逻辑讲得通吗？       | ✅ 稳定（100 项目实测）                  | ✅ 全开源                |
| **L2 指标量化层** | 成果量得出吗？证据有多强？ | ✅ 稳定（四维 D1-D4 + 证据五级 A-E）       | ✅ **v3.0.0 起全开源**    |
| **L3 价值评估层** | 值多少？          | 🧪 **v0.3 方法草案**（双轨制 · 方法演示已完成） | ✅ 全文 + 参考实现 + 验证案例开放 |

> **关于 L3 的定位说明**：L3 是**方法草案，不是行业标准**。  
> 货币化轨道目前全样本库仅 1 个 L2-A 验证案例，v0.2 §8 的四项待办尚未闭合。  
> 单一案例能证明方法跑得通，不能证明方法已稳定——把它称做"标准"，会把未验证的方法变成可被审计质疑的承诺。  
> 我们选择诚实标注成熟度，这既是对使用方负责，也符合本框架自己的「诚实归因」原则。

### L2 四维评分结构

```
L2 总分 = D1(25) + D2(30) + D3(25) + D4(20)，满分 100
```

| 维度         |  权重 | 核心问题                       |
| ---------- | :-: | -------------------------- |
| D1 成果指标质量  |  25 | 指标对准的是"成果"还是"产出"？          |
| D2 证据强度评级  |  30 | 证据有多硬？（A 独立因果验证 → E 无有效证据） |
| D3 因果链数据覆盖 |  25 | ToC 上有多少关键节点真有数据？          |
| D4 测量方法可信度 |  20 | 数据是怎么测出来的？                 |

分级：L2-A（85-100 深度验证级）/ L2-B（70-84 量化可信级）/ L2-C（50-69 指标初建级）/ L2-D（<50 未达标级）。  
**一票否决**：证据定 E 级时，无论总分多少最高只能判 L2-C。

### L3 双轨制（v0.3 草案）

- **货币化轨道**（溢价层 · 仅 L2-A）：SROI 元:元，≥2 种货币化方法交叉验证，给区间不给单点值；须经专业人员复核后方可正式发布
- **叙事轨道**（开放层 · L2-B/C）：证据强度陈述 + Contribution 声明，必须回答"没有这个项目会怎样"

**反事实四系数**（把 L1 的定性归因升级为可审计的量化算子）：

```
净贡献率 = (1 − Deadweight) × (1 − Attribution) × (1 − Displacement) × (1 − Drop-off)
          没你也会发生     别人的功劳别抢     把问题推给了别处     三年后还剩几成
```

**⚠️ 使用 L3 前必读**：`references/l3/l3-redline-double-deduction.md`

第三方专业机构发布的 SROI，绝大多数**已经内含**四系数调整。若再乘以本项目的自估净贡献率，就是把同一笔扣减做了两次——  
错误方向是**低估**，因此特别隐蔽：它会安静地产出一个看起来很保守、无人质疑的错数字。  
参考实现 `l3-calculator.ts` 对此实现了毛/净口径判定守卫，口径不明时按保守原则不派生。

## 怎么用

1. 把本目录放到你的 AI 助手的 skills 目录（WorkBuddy：`~/.workbuddy/skills/`；其他助手按各自约定）
2. 直接对话：
   - L1：`帮我体检一下这个项目` / `快速自检` / `评审这 5 份申请`
   - L2：`深度评估一下 XX 项目` / `证据有多强` / `指标盘点`
3. L2 有硬门槛：项目须先通过 L1（快检 ≥6 分 / 完整体检基础期及以上 / 3-5.5 分但 Q3Q4Q7 均达标），未通过会被退回先做 L1。

**离线可用**：全流程不联网、不依赖任何付费端点。若想与 223 个项目库做同类目对标，可**选配**接入 `sia-kb` MCP Server（见 SKILL.md 文末）。

## 使用边界

- 本框架是 **发展性评估工具**，不是审计工具，**不得用于财务/合规/问责审计**
- 输出为 **AI 辅助评估初稿**（AI 初评 + 人工复核质控），重大资助决策需结合人工尽调与专家判断
- L3 货币化轨道不建议在 L2-A 以下项目出具
- `sia_kb` 项目库原始采集数据不在本许可范围内：本仓库仅引用脱敏聚合统计，不分发原始数据（详见 `NOTICE.md`）
